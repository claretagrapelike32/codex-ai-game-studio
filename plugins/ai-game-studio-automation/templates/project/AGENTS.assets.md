# Game asset scope

Treat existing source assets as immutable inputs unless the user explicitly approves replacement. Write generated or enhanced variants to a separate preview/output location and retain provenance.

Validate rights and consent first. Then validate format, dimensions/scale, transparency or topology, normals/UV/PBR channels, rig and animation continuity, audio peaks/loops, LOD/collision, runtime budgets, and multi-view visual consistency as applicable.

Never upload private assets or identity/voice references to an external service without explicit permission. Unknown or custom commercial terms block production use until reviewed.
