# Codex AI Game Studio project guidance

Inspect before editing. State the detected engine, current project phase, target platform, and the smallest verifiable change before implementation.

For any external tool, model, asset generator, MCP server, or large download, present one consolidated transaction with exact pins, licenses, permissions, expected size, backups, and rollback. Wait for the user to confirm its digest before applying it.

Generated assets never replace source assets automatically. Preserve originals, record prompts and model/tool versions, create before/after evidence, and require human approval after rights, technical-format, visual/temporal, performance, and playability gates.

Prefer the project's existing engine, language, formatter, test runner, and asset conventions. Do not activate more than one MCP server for the same host application.
