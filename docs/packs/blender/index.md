# Blender pack

Default upstream: [`ahujasid/blender-mcp`](https://github.com/ahujasid/blender-mcp). Generative Blender add-ons remain external tools rather than silently enabled alternatives.

```text
codex plugin add ai-game-studio-blender@frabcd-ai-game-studio
```

The setup skill detects Blender/Python versions, add-ons, project paths, ports, and existing MCP control. The confirmed transaction constrains scene/filesystem/process/network permissions and finishes with a connection, scene query, reversible test object, cleanup, and rollback check.
