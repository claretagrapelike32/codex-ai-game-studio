# Pixel-art pack

Default upstream: [`willibrandon/pixel-mcp`](https://github.com/willibrandon/pixel-mcp). Pixelorama and Tiled are documented non-MCP alternatives and are never auto-installed.

```text
codex plugin add ai-game-studio-pixel@frabcd-ai-game-studio
```

The setup skill detects compatible editors and project sprite/tile conventions, then plans one adapter with permissions and pins. Validation covers transparent alpha, dimensions, palette/pixel-grid preservation, pivots/baselines, atlas padding, animation loops, import metadata, and rollback.
