# Godot pack

Default upstream: [`Coding-Solo/godot-mcp`](https://github.com/Coding-Solo/godot-mcp). The IvanMurzak implementation remains a selectable inactive alternative.

```text
codex plugin add ai-game-studio-godot@frabcd-ai-game-studio
```

The setup skill detects Godot version, language mix, renderer, installed editor, addons, and existing MCPs. After digest confirmation it can install only the pinned adapter listed in the transaction, then validate project import, parsing, connection, main-scene launch, and rollback.
