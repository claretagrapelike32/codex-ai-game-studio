# Support

Use [GitHub Discussions](https://github.com/frabcd/codex-ai-game-studio/discussions) for questions and workflow help, [GitHub Issues](https://github.com/frabcd/codex-ai-game-studio/issues) for reproducible bugs, and the repository's private security-advisory form for vulnerabilities.

Attach a redacted `doctor` result, relevant plan ID (not secrets), operating system, Codex surface, plugin version, and exact error. Do not attach proprietary assets, tokens, `.env` files, unconsented voice/identity data, or private repository content.

See the full [support policy](../../SUPPORT.md) and [troubleshooting guide](../TROUBLESHOOTING.md).
