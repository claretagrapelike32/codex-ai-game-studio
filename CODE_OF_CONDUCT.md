# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project respectful and harassment-free for everyone, regardless of background, identity, experience, or role.

## Expected behavior

Be constructive, specific, and considerate. Respect creative ownership, identity rights, voice consent, licenses, privacy, and the time of maintainers and contributors. Give credit, accept correction, and focus criticism on work and evidence rather than people.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized attention, deliberate license evasion, non-consensual identity or voice replication, and publishing others' private information are unacceptable.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile contact channel. Maintainers may edit or remove contributions, comments, issues, or other participation that violates this code and may temporarily or permanently restrict participation. Enforcement decisions will prioritize participant safety and privacy.

This compact code is inspired by Contributor Covenant 2.1 and may be replaced with the full upstream text in a future governance update.
