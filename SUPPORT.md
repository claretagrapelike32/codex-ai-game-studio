# Support

- Use **GitHub Discussions** for setup questions, workflow design, catalog comparisons, and show-and-tell.
- Use **GitHub Issues** for reproducible bugs and documentation defects.
- Use the private security-advisory flow described in [SECURITY.md](SECURITY.md) for vulnerabilities.

Before asking for help, run the read-only doctor and attach its redacted JSON output plus the validation summary. Never attach tokens, `.env` contents, private project assets, unpublished voice data, or proprietary model weights.

```text
python plugins/ai-game-studio/scripts/ai_game_studio.py doctor
python plugins/ai-game-studio/scripts/ai_game_studio.py validate platform
```

Community support is best effort. Optional external tools are supported by their respective maintainers, licenses, service plans, and privacy policies.
